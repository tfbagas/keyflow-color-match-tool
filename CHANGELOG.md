# Changelog

## [v1.0.0] - Initial Public Release

* Deterministic two-stage 3D OKLab color transfer solver baked into a 32³ tetrahedral LUT.
* Editable LUT lab: 5-zone tonal curve, 3-way color wheels, Hue 6V, and skin-tone protection.
* Pro Scopes: Histogram, RGB Parade, Vectorscope, Zebra / Clipping, False Color IRE.
* Universal export: `.cube`, `.lut`, `.ffx`, `.kfplug`, stills, and WebCodecs `.mp4`.
* Bilingual EN | ID interface, 100% client-side processing.
